# Klibaite 2025 conversion

Documentation of the conversion of the Klibaite 2025 social behavior dataset (Olveczky Lab) to NWB, for lab members
who run and extend it. For the conversion pipeline in general, see the [repository docs](../../../../docs/).

1. [Data organization](data_organization.md): the data share layout, cohorts, encounter rounds and lab files.
2. [Converting sessions](converting_sessions.md): converting sessions, inspecting and uploading the files, and the
   output files.
3. [Data streams](data_streams.md): pose, video, skin contacts, task and epoch, and how their times are aligned.
4. [Metadata](metadata.md): editing the metadata file, adding a cohort, HED tags and ontology terms.
5. [Excluded sessions](excluded_sessions.md): the sessions of the data share that are not converted, and why.
